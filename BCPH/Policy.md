# Privacy Policy for BC Parks Reservation Assistant

**Last Updated:** March 25, 2026

The "BC Parks Reservation Assistant" extension (the "Extension") is designed to assist users with campsite reservations. 

### 1. Data Collection and Usage
The Extension does **not** collect, store, or transmit any personal data or sensitive user information to any external servers. 

### 2. Local Processing
All data processing, including form filling and user preferences, occurs locally within the user's browser environment. 

### 3. Permissions
- **Storage:** Used to save your booking preferences locally on your device.
- **Tabs/ActiveTab:** Used to interact only with the BC Parks reservation website to provide the assistant interface.

### 4. Contact
For any questions regarding this policy, please contact harley4ik@gmail.com.
